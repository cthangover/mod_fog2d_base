# Видимость в 2D

Библиотека отделяет текущую видимость от сохранённого знания о местности. Изометрия и вид сверху используют одну сетку клеток. Память исследованного принадлежит общему `exploration_base`; этот мод не создаёт вторую копию битов в сохранении.

`Fog2dProfile` — настройки карты с тем же Id: радиус 1–64 клетки, яркость запомненного, дополнительные непрозрачные клетки, начально исследованные области и правила объектов. Полные сегменты закрывают обзор по умолчанию. Низкая мебель и NPC пропускают взгляд, пока автор явно не назначит другое правило. Режим `WhenSolid` связывает дверь с её обычными состояниями; отдельного состояния двери для тумана нет.

`Fog2dField.Compute` возвращает видимые индексы y × ширина + x. Первая непрозрачная клетка видна, расположенное за ней скрыто. Два закрытых края останавливают диагональный луч. Радиус измеряется между центрами клеток; край карты обрезает круг.

`Fog2dOcclusion` строит отделённую сетку для игры или предпросмотра, не открывая память исследования. `Fog2dObserver` связывает сетку с обычной RPG-сессией и общим сохранением. Вызывайте Update после изменения мира; Dispose при уходе с карты снимает текущую видимость, сохраняя исследованное. При загрузке игры Update сам открывает актуальное поколение памяти. Настройки копируются при создании наблюдателя; изменение авторского профиля требует его пересоздания.

Адаптер автоматически применяет профиль при подготовке обычного кадра RPG, в том числе при смене проекции. У карты без профиля остаётся прежнее изображение и не создаётся текстура маски. Отдельный fog2d_editor предоставляет выбор карты, настройки обзора, правила объектов, кисти начального открытия и отмену через формы. Карта местности — отдельный домен.

Материал тайлов поддерживает отключаемую маску: красный канал — исследовано, зелёный — видно сейчас. Нулевой красный канал скрывает картинку, исследованное вне обзора затемняется. Для вертикальной картинки `TileVisual.VisibilityCell` задаёт клетку опоры: верх изображения не обрезается клетками за ним. Плоские материалы и цельные комнаты проверяются по каждому пикселю. Статические quad-плоскости без отдельной клетки опоры используют реальные XY своих углов: высота стены не переносит её верх в посторонние клетки, а длинная стена сохраняет разделение по ширине. Crop учитывается в координатах картинки.

`RpgWorldView.FrameFiltering` вызывается после подготовки исходного кадра, включая первый кадр нового рендерера. Адаптер возвращает отдельное хранилище поз и не изменяет кэш мира. Видимые спрайты сохраняют плавную текущую позицию; запомненный рисунок используется только вне обзора. Текстуры берутся из существующего кэша мира, повторного декодирования для памяти нет. Отсутствие подписчиков и выключенная маска сохраняют прежнюю отрисовку.

`Fog2dWorld.MemoryOf(view)` возвращает заимствованный актуальный handle исследования именно указанного вида либо null без профиля или до согласования поколения после загрузки. `RefreshProfiles` снимает старые маски после авторского сохранения; обычный следующий кадр открывает копию новых настроек. Начальное открытие областей повторно к уже существующему сохранению не применяется. Нативная маска обновляется только при изменении исследования/видимости и освобождается при уходе вида, выгрузке мода и общем завершении приложения.

`Fog2dHistory.Observe` запоминает видимые динамические декорации. Невидимая смена состояния двери не раскрывается; увидев прежнее место предмета пустым, игрок запоминает его отсутствие. Заранее открытая область получает авторский базовый вид, а не текущее скрытое состояние. NPC не сохраняются как декорации. История копирует рисунок и не изменяет игровой объект; некорректные части проходят тот же числовой карантин, что и рендерер.

Обычный слот мода `RememberedScenes` хранит только отделённые рисунки и их последние клетки. Исследованные биты остаются в `exploration_base`. JSON проверяется и копируется целиком до замены живой истории; неподдерживаемая версия оставляет её прежней. Новый сеанс игры и выгрузка мода очищают старые рисунки. Самостоятельный вызов Reset истории не сбрасывает общую память исследованного.
